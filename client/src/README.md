# Job & Internship Marketplace

A full-stack MERN web application that connects students with companies for job and internship opportunities.

## 🚀 Project Overview

The Job & Internship Marketplace allows:

* Students to create accounts
* Students to search for jobs and internships
* Students to apply for jobs
* Students to track their applications
* Companies to create job postings
* Companies to view applicants
* Companies to update application status
* Users to manage their profiles
* Dashboards for students and companies

## 🔐 Authentication

The application uses JWT-based authentication.

Different permissions are provided based on the user's role:

* Student
* Company

Protected API routes require a valid authentication token.
